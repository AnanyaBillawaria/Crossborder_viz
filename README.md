# Global Financial Flows – Regional Direction Analysis  

This project visualizes the **direction and intensity of cross-border financial flows** across regions using BIS data from 2000-2024.


**Tools:** Python (matplotlib, cartopy), geopandas  

---

## Dataset  
- **Source:** BIS Locational Banking Statistics (LBS)  
- **Variables:** Total cross-border claims by reporting & counterparty countries
